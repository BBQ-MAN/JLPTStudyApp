JLPTStudyApp — 규칙 기반 자동 생성 연습 문제 (2026-11-08)

LLM·네트워크 없이 콘텐츠 DB의 검증된 데이터만으로 문제를 만드는 기능을 dev/quizgen에 구현했다. 유형은 한자 읽기·표기·뜻 고르기(일→한)·단어 고르기(한→일) 4가지다. 정답이 둘이 되는 문항은 전수 검사와 독립 점검 모두에서 0건이었다. main 커밋·병합·push는 하지 않았다.

1. 결정 대기(잠정 채택) 목록

하네스 추천안을 잠정 채택해 진행했다. 바꾸려면 ID와 고를 선택지를 알려 주면 된다. 상세는 docs/content/decisions.md Q-01~Q-10.

① 한자 읽기

지시문 밑줄 친 閉める의 읽기로 알맞은 것을 고르세요.
지문 閉める

보기정답오답 이유
じめる탁음·반탁음 표시가 다릅니다.
しめいる장음(길게 읽는 소리)이 다릅니다.

오답 배제 규칙

  • 그 단어의 JMdict 항목에 있는 모든 읽기(今日 きょう/こんにち)
  • 같은 표기를 가진 다른 항목의 읽기(上手 じょうず/うわて) — 목록 밖 항목은 related 스냅샷으로 포함
  • 변형 결과가 우연히 실제 읽기가 된 경우(日本 にほん→にっぽん)도 같은 검사로 제외

지시문 밑줄 친 しめる의 알맞은 표기를 고르세요.
지문 しめる

보기정답오답 이유
病める「閉」 대신 「病」를 썼습니다.
瓶める「閉」 대신 「瓶」를 썼습니다.
